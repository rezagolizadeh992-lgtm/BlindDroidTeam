# پناه | راهنمای آمادگی و واکنش به حوادث

اپلیکیشن بومی Android با Java و متن فارسی راست‌به‌چپ برای آمادگی و واکنش اولیه در زلزله، سیل، آتش‌سوزی طبیعی، طوفان و رعدوبرق، رانش زمین و گرمای شدید.

## امکانات

- راهنمای کوتاه «پیش از حادثه / هنگام حادثه / پس از حادثه» برای هر خطر
- دسترسی آفلاین به دستورالعمل‌ها
- دکمه تماس از طریق شماره‌گیر گوشی؛ بدون درخواست مجوز تماس مستقیم
- شماره‌های اضطراری ایران: ۱۱۲ هلال احمر، ۱۱۵ اورژانس پزشکی، ۱۲۵ آتش‌نشانی، ۱۱۰ پلیس
- فهرست قابل علامت‌گذاری برای کیف نجات
- فرم برنامه خانوادگی برای محل قرار، فرد رابط و یادداشت پزشکی؛ داده‌ها فقط روی گوشی ذخیره می‌شوند
- پیوند به منابع رسمی برای مطالعه بیشتر

## ساخت APK

نیازمندی‌ها: JDK 17 یا جدیدتر، Android SDK Platform 35، Android Build Tools 35.0.0 و Gradle 8.7 یا جدیدتر (پروژه با Gradle 8.9 و Android Gradle Plugin 8.6.1 تنظیم شده است).

```bash
bash scripts/bootstrap_build_tools.sh
source ~/.local/android-build/env.sh
gradle assembleDebug
```

فایل خروجی: `app/build/outputs/apk/debug/app-debug.apk`

برای ساخت انتشار، باید کلید امضای اختصاصی بسازید و پیکربندی signing را به پروژه اضافه کنید. فایل debug برای نصب و آزمایش است؛ برای انتشار عمومی مناسب نیست.

## نصب

APK را به گوشی Android منتقل کنید، فایل را باز کنید و در صورت درخواست Android، نصب از آن منبع را مجاز کنید. فقط APKای را نصب کنید که از منبع مورد اعتماد گرفته‌اید.

## حریم خصوصی و محدودیت

برنامه برای کارکرد اصلی به اینترنت، حساب کاربری، موقعیت مکانی، میکروفون یا دسترسی تماس نیاز ندارد. برنامه زلزله را تشخیص نمی‌دهد، هشدار زنده یا اطلاعات لحظه‌ای آب‌وهوا نمی‌فرستد و جایگزین آموزش رسمی، پزشک یا نیروهای امدادی نیست. شماره‌های پیش‌فرض اضطراری برای ایران‌اند؛ خارج از ایران شماره‌های معتبر منطقه خود را بررسی کنید. در هر حادثه، دستور مقام‌های رسمی محلی را در اولویت بگذارید.

محتوای ایمنی و پیوندهای منابع در [docs/SAFETY_SOURCES.md](docs/SAFETY_SOURCES.md) آمده است.
