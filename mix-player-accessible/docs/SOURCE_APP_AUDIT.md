# ممیزی فایل ورودی و دامنهٔ بازسازی

## فایل دریافت‌شده

- منبع: لینک Google Drive ارائه‌شده توسط کاربر
- نوع فایل: Android APK
- نام نمایشی: Mix Player
- شناسهٔ بسته: `com.blinddroid.mixplayer`
- نسخهٔ شناسایی‌شده: `1.7` (versionCode 8)
- SHA-256 فایل ورودی: `c6cabadc6c8b6de2d94a030d24a2bdf03988683eb5165a33877ec044c32bc1f9`
- امضای APK ورودی: معتبر با APK Signature Scheme v2

فایل ورودی، سورس Java/Kotlin یا پروژهٔ Gradle نبود. بررسی ایستا نشان داد برنامه یک پخش‌کنندهٔ محلی موسیقی با انتخاب پوشه/فایل، تنظیمات سرعت و زیر‌وبمی، جلو/عقب، تکرار، پخش تصادفی، تایمر خواب و برچسب‌های فارسی دسترس‌پذیری است. APK در این پروژه اجرا یا به‌عنوان کد خام ادغام نشده است.

## خروجی این پروژه

سورس Java در این پوشه از نو ساخته شده و بستهٔ نصب آن `com.blinddroid.mixplayer.accessible` است. امکانات کلیدی پخش‌کنندهٔ ورودی بازسازی و قابلیت‌های علاقه‌مندی، جست‌وجو، ذخیرهٔ موقعیت، اعلان/صفحه‌قفل و کنترل دسترس‌پذیر افزوده شده‌اند. این خروجی را باید به‌عنوان **بازسازی مستقل و آزمایشی** در نظر گرفت، نه انتشار رسمی سازندهٔ APK ورودی.

گواهی Debug خروجی با گواهی APK اصلی یکی نیست. شناسهٔ بسته نیز متفاوت است تا دو برنامه با هم تداخل نکنند؛ برای نصب نسخهٔ اصلی را لازم نیست پاک کنید.

## محدودیت آزمون

ساخت Gradle و بررسی ایستای APK انجام می‌شود، اما این محیط دستگاه Android یا TalkBack متصل ندارد. پیش از انتشار عمومی، نصب و پیمایش کامل با TalkBack فارسی، Voice Access یا Switch Access، اندازهٔ قلم بزرگ، اعلان‌ها و مجوز انتخاب پوشه روی چند نسخهٔ Android باید بررسی شود.
