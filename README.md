# پروژه‌های Blind Droid

این مخزن چند پروژه و فایل مرتبط با Blind Droid را نگه می‌دارد. پروژهٔ جدید **پناه** در کنار فایل‌های موجود اضافه شده است؛ محتوای قبلی Mixer Box و وب‌اپ آن حفظ شده‌اند.

## پناه | راهنمای آمادگی و واکنش به حوادث

اپلیکیشن بومی Android با Java و رابط فارسی راست‌به‌چپ است. راهنماهای آفلاین زلزله، سیل، آتش‌سوزی طبیعی، طوفان و رعدوبرق، رانش زمین و گرمای شدید را در کنار چک‌لیست کیف نجات و برنامهٔ خانوادگی ارائه می‌کند.

- [دانلود APK نصب و آزمایشی](panah-disaster-guide/panah-disaster-guide-debug.apk)
- [توضیحات، امکانات و راهنمای ساخت](panah-disaster-guide/README.md)
- [منابع رسمی محتوای ایمنی](panah-disaster-guide/docs/SAFETY_SOURCES.md)
- شماره‌های ۱۱۲، ۱۱۵، ۱۲۵ و ۱۱۰ در برنامه برای ایران هستند؛ بیرون از ایران، شمارهٔ اضطراری محلی را بررسی کنید.
- این نسخه هشدار زنده یا تشخیص زلزله ندارد. APK با امضای debug ساخته شده و برای نصب و آزمایش است، نه انتشار فروشگاهی.
