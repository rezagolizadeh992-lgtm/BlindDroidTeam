# پناه | راهنمای آمادگی و واکنش به حوادث

اپلیکیشن بومی Android با Java و رابط فارسی راست‌به‌چپ برای آمادگی و واکنش اولیه در بلایای طبیعی. راهنماها آفلاین‌اند و برای هر خطر، اقدام‌های پیش از حادثه، هنگام آن و پس از آن را نشان می‌دهند.

## دریافت و راه‌اندازی

- [دانلود APK آزمایشی](panah-disaster-guide/panah-disaster-guide-debug.apk)
- [توضیحات امکانات و راهنمای ساخت](panah-disaster-guide/README.md)
- [منابع رسمی محتوای ایمنی](panah-disaster-guide/docs/SAFETY_SOURCES.md)

برنامه راهنمای زلزله، سیل، آتش‌سوزی طبیعی، طوفان و رعدوبرق، رانش زمین و گرمای شدید دارد. چک‌لیست کیف نجات و برنامهٔ خانوادگی روی گوشی ذخیره می‌شوند. دکمه‌های تماس، شماره‌گیر گوشی را باز می‌کنند تا تماس را خودتان تأیید کنید.

شماره‌های ۱۱۲، ۱۱۵، ۱۲۵ و ۱۱۰ در برنامه برای ایران درج شده‌اند؛ خارج از ایران شماره اضطراری محلی را بررسی کنید. برنامه هشدار زنده، پیش‌بینی یا تشخیص زلزله ندارد؛ دستور مقام‌های رسمی محل را در اولویت بگذارید.

APK با امضای debug برای نصب و آزمایش ساخته شده و برای انتشار فروشگاهی مناسب نیست. مجوز مخزن در فایل [`LICENSE`](LICENSE) آمده است.

## Mix Player دسترس‌پذیر

بازسازی بومی Java از پخش‌کنندهٔ صوتی ارسالی کاربر، با رابط فارسی و تمرکز بر TalkBack و استفادهٔ کم‌بینا/نابینا:

- [دانلود APK آزمایشی Mix Player](mix-player-accessible/mix-player-accessible-debug.apk)
- [توضیحات قابلیت‌ها و راهنمای ساخت](mix-player-accessible/README.md)
- [گزارش فایل ورودی و دامنهٔ بازسازی](mix-player-accessible/docs/SOURCE_APP_AUDIT.md)

این برنامه بازسازی مستقل است؛ APK ورودی سورس اصلی نداشت. شناسهٔ برنامه متفاوت است و می‌تواند کنار نسخهٔ اصلی نصب شود. APK با کلید Debug امضا شده و پیش از انتشار عمومی به آزمون TalkBack روی دستگاه واقعی و امضای Release نیاز دارد.
